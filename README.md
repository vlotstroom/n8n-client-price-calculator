# n8n client price calculator

Free single-file calculator for freelancers and agencies quoting n8n
automation work: build hours by workflow complexity, discovery, data
migration, hand-over and a testing buffer, then the quote at your own
hourly rate, plus the monthly retainer with hosting passed through.

- Open `index.html` in any browser, or use the hosted copy:
  https://vlotstroom.github.io/n8n-client-price-calculator/
- English + Nederlands, no signup, no external requests, nothing sent.

Honest arithmetic, no benchmarks claimed:

- Every default hour is an editable starting point, not a rate card.
- Quote = (workflow hours + option hours) x (1 + buffer%) x your rate.
- Retainer = maintenance hours x rate + hosting you pass through
  (shared VPS cost divided by clients, or a dedicated plan you name).
- The quote checklist names what maintenance includes and excludes,
  and keeps variable API costs on the client's own accounts.

Defaults grounded in practitioner advice from r/n8n pricing threads
(1-2 maintenance hours per client per month on a mature setup, VPS
$6-12/month shared across several clients, explicit include/exclude
lists, usage caps on variable API costs).
