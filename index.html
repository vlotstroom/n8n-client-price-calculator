The floor is what the work costs if nothing surprises you. The quote carries the buffer for the edge cases that were not in scope. Scope creep after sign-off belongs in a change order, not in a bigger quote now.

3. Monthly retainer

Never absorb variable API costs (AI calls, SMS, OCR, enrichment) in a flat retainer. Run the workflows on the client's own accounts and keys, and set a monthly usage cap: above the cap, pause or ask for approval. Practitioners report the API bill is where flat-fee deals go wrong, not the hosting.

4. Quote checklist

Name what the maintenance retainer includes:

  • small fixes and workflow error fixes, with an error alert to you
  • hosting and uptime of the instance, if you host it
  • a short monthly report: runs, failures, fixes done

Name what it does not include, priced separately:

  • new features and new workflows
  • changes to the core of an existing workflow
  • third-party usage above the agreed monthly cap

Split the money:

  • your fee covers consultation, setup and maintenance
  • subscriptions and API keys stay in the client's name
  • retainers typically run 6-12 months; longer locks a better rate
